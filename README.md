A minecraft texture pack which adds: firefighting tools to minecraft using CIT mods (for example: Optifine).


it adds:

Halligan bar (pickaxe)
Jaws of life (pickaxe)
Fire axe (axe)
Spreaders (sword)
Cutters (shears)
Pulaski (hoe)
Fire beater (shovel)
Scbamask (elytra)

(all Diamonds/Netherite only (except Elytra))
